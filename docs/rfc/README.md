# RFCs — Request for Comments

Propostas técnicas discutidas pelo time antes de virarem decisão firme. Diferente dos [ADRs](../adr/README.md), que registram uma decisão fechada, uma RFC carrega a análise de alternativas, o impacto de custo e as questões em aberto.

Quando uma proposta estabiliza, sua conclusão vira ADR. Enquanto isso, a RFC é o documento vivo.

## Convenções

- Numeração sequencial, sem buracos.
- Formato: **Resumo**, **Motivação**, **Proposta**, **Alternativas avaliadas**, **Impacto no custo**, **Riscos**, **Questões em aberto**.
- Status: `Rascunho`, `Em discussão`, `Aceita`, `Rejeitada`, `Substituída pela RFC-XXXX`.
